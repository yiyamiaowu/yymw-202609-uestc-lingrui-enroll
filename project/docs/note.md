# 数据预处理

## 数据清洗

1. 删去Cabin，Ticket
2. 平均值填充Age

## 特征工程

1. 将SibSp与Parch合并为同行人数Companion，并增加Isalone列
   $Companion=1+SibSp+Parch$
2. 将Age，Fare归一化
3. Pcclas做one hot处理
4. Sex做one hot处理
5. 众数填充缺失，Embarked做one hot处理
6. 提取称呼，并删去Name

ps:原本想用不同性别，仓位，港口的存活率来代替非数值型的特征，但是感觉这样做就失去了训练模型来预测的意义，毕竟这样的话这几个量就与是否存活强相关了，模型可能会只关注这几个量，所以采用了onehot

ps:最初直接把Name这一列删去了，但在后期改进时，通过问ai了解到称呼其实很重要，故增加了这一列，在结果中有标出（这一部分因为统计整个891条数据太麻烦，所以求助了ai）

## 分层抽样

按照8：1：1划分了训练集，验证集与测试集，并使三组中生还的比例接近原数据集

ps:最初采用的是随机取样，但这样抽出来的结果会使的训练结果方差极大，所以换成了分层抽样

# 模型搭建

## 模型选择

**更新**
Kaiming初始化，用Xavier初始化时模型训练收敛很慢，而且效果甚至不如原来
逻辑回归模型处理二分类任务
加入隐藏层Linear(17,32)，ReLU，Dropout，Linear(32,16)，ReLU，Dropout，Linear(16,1)，Sigmoid
感觉像是ReLu和Dropout都是通过降低维度来引入非线性，所以前面的Linear就先增大维度，后面合并减少，以此来让模型认识不同类别样本它对于判断的影响是不同的
激活函数：sigmoid
损失函数：二元交叉熵损失
优化算法：Adam

## 超参数设置

epoch = 2000
学习率0.01时震荡，故设置为0.001
模型在最初训练时发现到末尾时验证集准确率下降，有过拟合的倾向，故采用正则化与早停
正则化设置为L2
patience：30
min_delta = 0.001

# 结果

多次更换种子后，发现模型在最终测试集的准确率为0.7640~0.8764之间
